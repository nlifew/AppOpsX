### 简介

1. **这个应用是干嘛的？**
   * 忽略权限，避免部分应用强行申请权限
   * 可以控制禁止网络访问（需要 Shizuku 以 root 方式运行）
2. **有哪些使用场景？**
   * 想要干净的通知栏？关闭应用使用通知栏权限！
   * 不想让应用读取剪贴板？关闭读取剪贴板权限！
   * 想让某个应用处于静音状态？使用显示默认权限，然后关闭播放声音的权限！
   * 不想让应用联网？禁止 WiFi/移动数据都可以！
   * 还有禁止读取通讯录/短信等等更多使用场景。
3. **这个应用收费吗？**
   本应用 **完全免费无广告！** 所有代码开源托管在 [GitHub][1]。
4. **如何反馈问题？**
   在 GitHub 提交 [issues][2]，并附上 AppOpsX 设置 → 显示日志 中的信息。

### 开始使用

AppOpsX 需要 Android 13 及以上，并通过 [Shizuku][3] 获取修改权限所需的系统权限。

1. 安装并启动 Shizuku：
   * 没有 root：在开发者选项中开启无线调试，然后在 Shizuku 中按提示配对并启动；
   * 有 root：在 Shizuku 中直接以 root 启动，或者使用 Sui。
2. 打开 AppOpsX，在 Shizuku 的授权弹窗中选择允许。

### 使用过程中的一些问题

1. **提示“Shizuku 未运行”怎么办？**
   请先打开 Shizuku 应用确认它已经启动。手机重启后 Shizuku 会停止，需要重新启动。

2. **提示“尚未授予 AppOpsX Shizuku 权限”怎么办？**
   在 AppOpsX 设置中点击 Shizuku 一项重新申请。如果之前选择了拒绝且不再询问，就不会再弹出授权窗口，请到 Shizuku 应用的授权管理中为 AppOpsX 授权。

3. **为什么看不到 WiFi/移动数据的开关？**
   联网控制通过 iptables 实现，需要 root 权限。只有 Shizuku 以 root 方式运行时才可用，通过无线调试启动的 Shizuku 不支持。

4. **为什么有一些权限关闭后又自动打开了？**
   有一些权限用 appops 改动并不会生效，所以再次查看的时候会发现又自动打开了。

5. **为什么我禁止了 WiFi/网络访问，重启后又生效了？**
   因为 iptables 规则重启后会失效。解决方法是在应用配置完成后使用 **导出** 功能导出配置，下次重启后恢复权限配置即可。

6. **“允许后台运行”是什么意思？**
   开启后，AppOpsX 退出时，Shizuku 中运行的 AppOpsX 服务会继续保留，下次打开不需要重新启动服务。关闭后，退出 AppOpsX 时服务也会停止。也可以在设置中手动“关闭后台服务”。

7. **为什么安装新应用后没有弹出自动关闭权限的提示？**
   在 Android 10 及以上的系统上，这个提示目前只有在 AppOpsX 正在前台时才会出现，后续版本会改进。在此之前，请在安装后手动调整新应用的权限。
